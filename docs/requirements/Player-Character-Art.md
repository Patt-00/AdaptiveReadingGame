# Provisional player character artwork

The two servant portraits were generated as provisional art for review by the story author and the group. Both appearances represent the same unnamed servant, and neither changes the story, pronouns, choices, or scoring. The images use the existing `Amelia_Neutral.png` as a style reference; they are not approved final character designs.

- Appearance A: `assets/characters/Servant_A.png`
- Appearance B: `assets/characters/Servant_B.png`

The built-in image generation tool received the following prompts, each with the reference image and a transparent-background request.

## Appearance A prompt

```text
Use case: illustration-story. Create an original full-body visual-novel character sprite of a young adult palace servant, appearance A: feminine presentation, medium brown hair tied neatly, modest ivory blouse and deep burgundy waistcoat with simple dark skirt and discreet gold accents, calm neutral expression, relaxed front-facing stance. Match the provided reference's clean hand-drawn anime illustration, fine outlines and soft painterly shading; the reference is style inspiration only, do not depict or duplicate the same character or clothing. Full figure visible, centered with room around hands and feet. Transparent background. No text, no watermark, no objects or additional people.
```

## Appearance B prompt

```text
Use case: illustration-story. Create an original full-body visual-novel character sprite of a young adult palace servant, appearance B: masculine presentation, neat dark brown hair, modest ivory shirt and deep burgundy waistcoat with simple dark trousers and discreet gold accents, calm neutral expression, relaxed front-facing stance. Match the provided reference's clean hand-drawn anime illustration, fine outlines and soft painterly shading; the reference is style inspiration only, do not depict or duplicate the same character or clothing. Full figure visible, centered with room around hands and feet. Transparent background. No text, no watermark, no objects or additional people.
```

To replace either provisional portrait, keep the existing filename key so saved account preferences continue to resolve. Review the artwork and the player's story identity with the group before final approval.
